# 🧪 아웃브레이크 랩 (Outbreak Lab)

좀비 팬데믹과 실제 감염병(🦠 현실 모드)을 같은 엔진으로 돌리는 확산 예측 시뮬레이션.
(구명: 좀비 바이러스 확산 시뮬레이션 — 2026-11-03 개명)

> **v2 — 🌍 세계 팬데믹** (`world.html`): 172개국 실제 인구·국경·항공망 위에서 벌어지는
> 국가 단위 확산 + 개입 게임. 아래 [v2 섹션](#-v2--세계-팬데믹-worldhtml) 참고.
> **v1 — 단일 월드 에이전트 시뮬레이션** (`index.html`): 이 문서의 본문.

에이전트 기반(agent-based) 좀비 확산 시뮬레이션 + 실시간 트렌드 예측 데모.
**의존성 없는 단일 HTML 파일**이라 `index.html`을 더블클릭하면 바로 실행됩니다.

## 실행 방법

- 가장 쉬운 방법: Finder에서 `index.html` 더블클릭 → 브라우저에서 열림
- 또는 로컬 서버: `python3 -m http.server 8931 --directory .` 후 http://localhost:8931

**▶ 시작**을 누르면 시뮬레이션이 돌아갑니다. (스페이스바 = 시작/일시정지, 1×/2×/4× 배속)

## 어떻게 동작하나

두 층으로 구성돼 있습니다.

1. **시뮬레이션 (왼쪽)** — 개별 에이전트들이 2D 월드를 돌아다닙니다.
   - 파란 점(생존자): 평소엔 배회하다가 좀비가 가까이 오면 도주
   - 주황 점(좀비): 근처의 생존자를 추격, 접촉하면 조우 판정
   - 조우 시: 먼저 **반격 성공률**로 좀비 제거 판정 → 실패하면 **감염 확률**로 감염 판정 → 둘 다 실패하면 탈출
2. **트렌드 예측 (오른쪽 차트의 점선)** — 시뮬레이션이 만들어내는 관측 데이터(감염·사살 빈도)로
   전파율 **β̂** 과 제거율 **κ̂** 을 실시간 추정하고, SZR 역학 모델
   (`dS=-βSZ/N`, `dZ=(β-κ)SZ/N`, `dR=κSZ/N`)을 앞으로 적분해 미래를 예측합니다.
   - **확산지수 = β̂/κ̂** : 1보다 크면 전멸 위험, 1보다 작으면 진압 우세
   - 점선(예측)과 실선(실측)이 얼마나 맞는지 비교하는 게 포인트

## 파라미터

| 슬라이더 | 의미 | 팁 |
|---|---|---|
| 인구 / 초기 좀비 | 리셋 시 적용 | 초기 좀비가 적으면 초동 진압으로 조기 종식되기도 |
| 감염 확률 | 조우 시 감염될 확률 | |
| 반격 성공률 | 조우 시 좀비를 제거할 확률 | **~37%가 티핑 포인트** (기본 감염 60% 기준) |
| 좀비/인간 속도 | 추격·도주 속도 | 인간이 좀비보다 빠르면 확산이 급감 |

실행 중에도 감염 확률·반격 성공률·속도를 바꾸면 바로 반영되고, 예측도 곧 따라 갱신됩니다.
(예: 확산 중에 반격 성공률을 50%로 올리면 예측이 "전멸 위험 → 진압 우세"로 뒤집히는 걸 볼 수 있어요)

## 콘솔 API (개발자 도구)

브라우저 콘솔에서 스크립트로 실험할 수 있습니다.

```js
zombieSim.runSteps(1000)              // 1000스텝 즉시 진행 후 상태 반환
zombieSim.state()                     // {t, S, Z, R, outcome, beta, kappa}
zombieSim.restart()                   // 리셋
zombieSim.setParams({pKill: 0.5})     // 파라미터 직접 변경 (슬라이더와 별개)
```

### 🎬 영화 시나리오

컨트롤의 **시나리오** 드롭다운에서 선택하면 발생지·전파율·제거율·항공량·좀비 소멸률(δ)·백신 속도가
그 영화 설정으로 세팅된 채 리셋된다. 슬라이더를 건드리면 "직접 설정"으로 풀린다.

| 시나리오 | 발생지 | 잠복기 | 특징 |
|---|---|---|---|
| 부산행 | 한국 | **즉시** | β 0.55 초고속 감염 — 감염자·좀비가 교통편으로 퍼진다 |
| 월드워Z | 무작위 | **즉시** | 물리면 초 단위 발현(영화의 12초). 항공 확산은 좀비 밀항으로 |
| 28일 후 | 영국 | **즉시** | 분노 바이러스(10~30초 발현), 감염자는 빨리 스러짐(δ 0.05) |
| 나는 전설이다 | 미국 | **5일** | 긴 잠복 + κ 0.12 사냥 곤란 — 자동 대응으로도 붕괴(D+~255) |
| 워킹데드 | 미국 | 3일 | β 0.22 슬로우번 장기전 |
| 킹덤(조선) | 한국 | 1일 | 항공 0 — 육로로만 퍼지는 근세 팬데믹 |

### 🦠 잠복기 모델 (SEZR, 2026-08-10 추가)

구획이 S → **E(잠복)** → Z → R로 확장됐다. 잠복기 슬라이더(0.5~10일, 기본 2일)로 1/σ를 조절한다.

- **국경·항공을 넘는 주체가 잠복자(E)** — 겉보기에 사람이라 검역을 통과한다 (육로는 좀비 배회분 30% 가산).
  잠복기가 길수록 국제 확산이 넓고 조용하다 (나는 전설이다가 최악인 이유).
- **탐지는 좀비화(전환) 기준**: 누적 전환 800명 전까지 지도에 안 보이고, 잠복 유입은 그보다도 늦게 드러난다.
- **재발생**: 진압 판정된 나라도 잠복 감염이 남아 있으면 다시 터진다 (상황 일지에 "재발생" 로그).
- 세계 잠복 규모는 좀비 타일에, 국가별 추정치는 상세 패널에 표시. 승리 조건도 좀비+잠복 모두 0.
- 밸런스(재측정): 무개입 붕괴 D+750~970 (잠복이 성장 속도를 늦춤) · 자동 대응 기본 진압(생존 ~100%) ·
  부산행 89% · 월드워Z 98% · 28일 후 경계선 · 나는 전설이다 붕괴 · 킹덤/워킹데드 진압.

### 🧬 변이·물리 살상·인구 동태 (2026-08-10 추가)

- **변이 시스템**: 세계 감염 규모(잠복+좀비)에 비례해 변이가 출현한다 (그리스 문자 명명: 알파·베타·…).
  변이마다 전파력 +6%(누적 최대 1.5×)이고, 백신 배포 중이면 **효율이 ×0.35로 급락** — WHO(자동) 또는
  연구 투자(수동, +12%p/회)로 개량해 92%까지 회복해야 한다. 백신 완성 = 무적이 아니게 됐다.
- **물리 살상(α=0.08/일)**: 좀비는 물어서 감염시키기만 하는 게 아니라 사람을 죽인다.
  접종자도 감염은 안 되지만 공격당해 죽는다 — 사망 타일이 "좀비 제거 · 희생"으로 분해 표시.
- **자연 출생·사망**: 출생 ~18/1000/년, 자연사 ~8/1000/년. 장기전에서 인구가 회복되며
  신생아는 미접종(S)이라 접종률이 저절로 희석된다. 생존율이 100%를 넘을 수 있는 이유.
- **즉시 발현(잠복기 0)**: 잠복기 슬라이더 0 = 물리면 그 자리에서 전환. 즉시 발현 바이러스는
  잠복자가 비행기를 못 타므로, 항공 확산은 **좀비 밀항 항**(승객 대비 0.6%)으로만 일어난다.
- 밸런스(재측정): 자동 대응 기본 진압(~100%) · 부산행 78% 신승~변이 연쇄 붕괴(시드에 따라) ·
  월드워Z 97~98% · 28일 후/나는 전설이다 붕괴 · 무개입 D+573~679 붕괴(변이가 가속).

- **계절성**: 위도 기반 겨울 파동 — 고위도에서 겨울엔 좀비가 굳어 확산 최대 -20% (❄️ 변이가 이를 무효화).
- **백그라운드 지속**: 워커 틱 덕분에 탭이 백그라운드여도 시뮬레이션이 계속 돈다 (복귀 시 렌더).

### 🦠 현실 모드 — 실제 병원체 프리셋 (2026-11-03 추가)

> **문헌 기반 교육용 단순화 모델 — 실제 방역 판단에 사용 금지.**
> 아래 수치는 WHO/CDC 자료와 역학 문헌의 통용 범위를 일 단위 SEIR 근사에 맞게 **대략값으로 단순화**한 것이다.
> 연령 구조·접촉망·치료제·실제 NPI 강도가 없으므로 절대 수치(특히 누적 사망)는 실제와 다르다.
> 모델이 재현하는 것은 **정성적 패턴**(박멸 가능/불가능, 풍토병화, 파동)이다.

- **용어**: 좀비→감염자 · 반격 제거율→격리·치료율 κ · 좀비 수명→감염 기간 · 암흑의 시대→엔데믹
- **동역학 차이**: 물리 살상(α) 꺼짐 · 감염 종료 시 IFR 비율만 사망, 나머지는 **회복→면역 풀(V)** 합류 ·
  면역은 `imm`일 시간 상수로 소멸(재감염) · **발증 전 전파**(`epre`: E 구획도 전파력 기여) ·
  재감염은 중증 보호(누적 감염 비율에 비례, 최대 70% 치명률 감소) · 의료 붕괴 시 치명률 ×1.5
- **변이 항원성**(`vesc`): 변이 출현 시 백신·면역 효율에 곱해지는 유지율. 1이면 항원 안정(홍역·에볼라·사스 —
  면역 회피 없음), 0.35면 코로나처럼 변이마다 면역이 크게 뚫림
- **생존 집계**: 현실 모드에서는 잠복(E)·감염(Z) 중인 사람도 생존자로 센다 (좀비 모드에서는 제외)

### 🤖 자동 대응 모드 (기본) vs 🎮 수동 개입 모드

HUD 토글로 전환한다.

- **자동 대응 (관전·예측 모드)**: 각국 정부가 *확인된 정보만 보고* 스스로 대응한다 —
  자국 감염 확인 → 방역 통제, 위기(감염률 0.05% 또는 좀비 5만) → 군 투입,
  인접국 감염 → 국경 봉쇄, 항공 연결국 감염 → 공항 폐쇄. WHO는 첫 확인 60일 후 백신 연구를 자동 진행.
  국가마다 **대응 지연 5~30일**과 **집행력 55~100%**가 랜덤 부여되어 신속한 나라와 굼뜬 나라,
  방역이 안 먹히는 나라가 생기고, 정책 만료 후 재발동 공백에서 파동이 나온다.
  기본 파라미터 자동 결말: 진압 성공(생존 ~100%) · 부산행 62~78% 신승 · **28일 후/나는 전설이다는 자동 대응으로도 문명 붕괴**.
- **수동 개입 (게임 모드) — "당신이 WHO다"** (2026-11-03 재설계, 2026-11-04 리밸런스): 각국 정부는
  자동 모드와 똑같이 자국을 지키지만, **WHO가 없다** — 백신 연구·개량과 국제 공조가 플레이어 몫이다.
  시작 RP 150. 플레이어 전용 수단(각국 정부는 못 하는 것):
  - **🪖/🧪 추적·격리(군 투입)**: 용량 포화형 — 유행이 그 나라 인구의 0.05%를 넘으면 급감. **작을 때
    치면 압도적, 늦으면 무딘 칼** (사스 2003·대만식 창문). 잠복자 색출로 발증 전 전파에도 대응.
  - **선제 차단 할인**: 공식 확인 전 국가의 국경·공항은 ½가 — ✈의심 로그·점선 예측을 보고 미리 막는
    '예측 베팅'. 수동 공항은 98% 차단, 국경은 난민 유출도 절반.
  - **백신**: 연구·개량 투자(50 RP·쿨다운 20일).
  봇 1,200판 실측: 시나리오마다 최적 경로가 다르다 — 부산행·28일후는 **조기 봉쇄 박멸**(부산행 최적
  D+51, 28일후는 자동 1.7% vs 수동 봉쇄 100.2% 생존), 월드워Z(동시다발 5개국 기원)·에볼라·사스는
  **백신/격리**, 코로나는 균형. 판이 끝나면 **S~F 등급 + 봇 분포 상위 N% + 자동 정부 대비 사망 Δ**가
  배너와 결과 분석 탭에 뜬다 (`qa/bot-runs-2026-11-04.json` 기준선).

## 핵심 발견 (밸런스·설계)

1. **수동 모드에서 좀비 시나리오는 사실상 방어 불가.** busan·wwz에서는 수동 봇 전원(방역·군사·국경·균형 모두)이 생존 0.7%의 폐허 승리 — 자동 정부(86.6~105.6%)와 극명한 대비. 수동 모드는 각국 자동 대응이 꺼진 채 RP ~10/일로 172개국을 감당해야 하기 때문. 기본 좀비(custom)에서만 masker(101.5%)·vax_rush(97.7%)가 방어에 성공. → **수동 모드 밸런스 재조정 후보** (예: 수동 모드에서도 약한 자동 대응 유지, 또는 RP 수입 상향).
2. **"어중간한 억제의 함정" (코로나)**: 10년 누적 사망 — 무개입 6.9% < 자동 정부 14.7%, 강한 개입(balanced) 2.3%. 약한 억제는 유행을 길게 끌며 변이 12종의 파동마다 사망을 누적시킴. 박멸(win)도 balanced가 4/10으로 최다. 모델의 의도된 동역학이지만 실제 방역 상식과 어긋나 보일 수 있음 — README 한계(치료제·개량 백신 부재) 각주감.
3. **사스 2003 역사 재현 선명**: 정부 대응 시 10/10 박멸·사망 ~0%, 무개입 시 0/10 박멸(엔데믹·변이 6종·사망 2.2%). "격리만으로 박멸이 가능했던 이유"가 봇 데이터로 증명됨.
4. **legend(나는 전설이다)는 전 봇 0승** — 알려진 자동 붕괴 특성 유지. days28도 전원 승리하나 생존 1~5%(문명 붕괴 후 소탕).
5. **에볼라·busan(자동)은 봇과 무관하게 조기 종결** — 저전파 병원체는 개입 여지 자체가 작음.
6. 밸런스 회귀: 자동 기본 좀비 101.4%(win 10/10), busan 자동 86.6% — 기존 실측 범위와 일치.

## 재현 방법

```
# world.html을 새로 로드한 브라우저 콘솔에서
fetch('/tools/qa-bots.js').then(r=>r.text()).then(eval);
__qaInit();          // {total:1000, startScenario:'custom', warn:null} 확인
__qaStep(50);        // 반복 호출 (진행률·위반 수 반환)
__qaExport(0,1000);  // JSON
```

주의: `scenario('custom')`은 직전 파라미터를 상속하므로 **반드시 새로 로드한 페이지에서** 시작(매트릭스가 custom을 맨 앞에 두는 이유). 엔진의 RNG는 시드 고정이지만, 엔진 수정으로 rand() 소비 순서가 바뀌면 같은 시드라도 과거 기록과 다른 궤적이 나온다(이번 binom 수정이 그 사례).
